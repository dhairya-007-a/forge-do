2. ARCHITECTURE (IMPORTANT - READ BEFORE CHANGING ANYTHING)
======================================================================
- 100% static site. No build step, no npm, no bundler, no framework.
- index.html and student-dashboard.html are the SAME file, kept byte-identical
  on purpose. Every change to index.html must be copied over student-dashboard.html
  (cp index.html student-dashboard.html) before considering a task done.
- admin-dashboard.html is a SEPARATE page (own login gate), reads the same
  browser's localStorage as index.html to show real activity stats.
- All "real data" lives in the browser's localStorage. There is NO database.
  If the browser's storage is cleared, all progress/history is gone.
- ONE serverless function exists: netlify/functions/generate-note.js
  - Calls the Anthropic API server-side (key never touches the browser).
  - Needs ANTHROPIC_API_KEY set as an env var on Netlify (and in local .env
    for `netlify dev`) - NOT hardcoded anywhere in committed files.
  - STATUS: key is valid but Anthropic account has $0 credit balance as of
    last check. Every real call 400s with "credit balance too low" until
    credits are added at console.anthropic.com -> Plans & Billing.
  - When it fails (no credits, no network, opened via plain file://), the
    Notes feature silently falls back to a small local hardcoded note bank
    (NOTES_BANK: stacks/queues/linked lists/BSTs only) and shows the
    blinking-face "Couldn't reach Forge AI" error animation.
- Opening the HTML files by double-click (file://) means the Netlify function
  and cross-page localStorage sharing are NOT reliable in all browsers.
  For real testing, use `netlify dev` locally or the deployed Netlify URL.
