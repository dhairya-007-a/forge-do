# Real Student Accounts + Admin Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every student a real account (identified by email, no password) that syncs their full `forge-*` localStorage snapshot to a Netlify Blob in real time, restores it on any device that re-enters the same email, and lets admin see a summary list of every account with a hard-delete button.

**Architecture:** Four thin Netlify functions (`sync-account.js`, `restore-account.js`, `list-accounts.js`, `delete-account.js`) sit on top of one shared helper `netlify/functions/_account-store.js` (same "one shared helper, thin call sites" pattern as `_groq-client.js`) which wraps `@netlify/blobs`'s `getStore()`. On the frontend, `index.html`'s existing `forgeStore` wrapper gets a debounced auto-sync hook added directly to its `setItem` method (no changes needed at the 15 existing call sites), and the onboarding submit handler gains a "check for an existing account first" step. `admin-dashboard.html` gets a second tab showing the account list with per-row delete.

**Tech Stack:** `@netlify/blobs` (new dependency), Node.js (CommonJS), vanilla JS/HTML frontend, no test framework in this repo (plain `node` scripts for verification, same as the Groq failover plan).

**Spec:** `docs/superpowers/specs/2026-08-05-real-accounts-admin-panel-design.md` (Approved)

**Known constraint (confirmed with user):** `@netlify/blobs` requires a real Netlify site context (site ID + token) to actually read/write — it cannot run against plain `node -e` or this project's stdlib-only `local-server.js` the way the Groq functions could, because Blobs isn't just an HTTP call with an API key, it's tied to a specific deployed site. The user has an existing (currently unused) Netlify site from a prior one-time deploy, but explicitly said not to wire up credentials right now — build the feature correctly, verify function *logic* locally via a mocked `@netlify/blobs` (same technique as `_groq-client.selfcheck.js` mocking `fetch`), and defer live end-to-end verification to the next real deploy. Every task below reflects this: "smoke tests" here mean mocked-dependency logic tests, not live network calls.

- [ ] **Step 1: Write `_account-store.js`**

```js
// Shared Netlify Blobs wrapper for the "accounts" store. Filename starts with `_` so
// Netlify's function router ignores it (no exports.handler here). Centralizes the
// account key naming (account:<lowercased email>) and the shape of what gets stored
// so the 4 thin handler functions (sync/restore/list/delete-account.js) don't each
// reimplement it.
const { getStore } = require('@netlify/blobs');

function store(){
  return getStore('accounts');
}

function keyFor(email){
  return 'account:' + String(email).trim().toLowerCase();
}

async function getAccount(email){
  const record = await store().get(keyFor(email), { type: 'json' });
  return record || null;
}

async function setAccount(email, data){
  await store().setJSON(keyFor(email), { data, lastSyncedAt: new Date().toISOString() });
}

async function deleteAccount(email){
  await store().delete(keyFor(email));
}

async function listAccounts(){
  const { blobs } = await store().list({ prefix: 'account:' });
  const accounts = [];
  for(const b of blobs){
    const record = await store().get(b.key, { type: 'json' });
    if(!record) continue;
    let profile = {};
    try{ profile = record.data && record.data['forge-profile'] ? JSON.parse(record.data['forge-profile']) : {}; }
    catch(e){ /* malformed profile — skip fields, still list the account */ }
    accounts.push({
      email: b.key.slice('account:'.length),
      firstName: profile.firstName || '',
      lastName: profile.lastName || '',
      course: profile.course || '',
      semester: profile.semester || '',
      batch: profile.batch || '',
      lastSyncedAt: record.lastSyncedAt || null
    });
  }
  accounts.sort((a, b) => (b.lastSyncedAt || '').localeCompare(a.lastSyncedAt || ''));
  return accounts;
}

module.exports = { getAccount, setAccount, deleteAccount, listAccounts, keyFor };
```

```js
  await deleteAccount('a@x.com');
  assert.strictEqual(await getAccount('a@x.com'), null);
  const afterDelete = await listAccounts();
  assert.strictEqual(afterDelete.length, 1);
  assert.strictEqual(afterDelete[0].email, 'b@x.com');
```

## Task 3: Create `sync-account.js`

- [ ] **Step 1: Write the function**

```js
// Netlify serverless function — receives a full forge-* localStorage snapshot from
// the frontend (debounced, sent after any change) and writes it to that email's
// Blob. Best-effort from the frontend's perspective: see index.html's runSync()
// for how failures here are swallowed client-side rather than shown to the student.
const { setAccount } = require('./_account-store');

exports.handler = async function(event){
  if(event.httpMethod !== 'POST'){
    return { statusCode: 405, body: JSON.stringify({ error: 'Method not allowed' }) };
  }

  let email, data;
  try{
    const body = JSON.parse(event.body || '{}');
    email = (body.email || '').trim();
    data = body.data;
  } catch(e){
    return { statusCode: 400, body: JSON.stringify({ error: 'Invalid request body' }) };
  }

  if(!email || !email.includes('@')){
    return { statusCode: 400, body: JSON.stringify({ error: 'a valid email is required' }) };
  }
  if(!data || typeof data !== 'object' || Array.isArray(data)){
    return { statusCode: 400, body: JSON.stringify({ error: 'data is required and must be an object' }) };
  }

  try{
    await setAccount(email, data);
    return { statusCode: 200, body: JSON.stringify({ ok: true }) };
  } catch(e){
    return { statusCode: 502, body: JSON.stringify({ error: 'Failed to write account: ' + e.message }) };
  }
};
```

```js
// Netlify serverless function — called once at onboarding submit to check whether
// the entered email already has a Blob (returning student, new device) and if so
// return its data so the frontend can restore it instead of starting fresh.
const { getAccount } = require('./_account-store');

exports.handler = async function(event){
  if(event.httpMethod !== 'POST'){
    return { statusCode: 405, body: JSON.stringify({ error: 'Method not allowed' }) };

  if(!email || !email.includes('@')){
    return { statusCode: 400, body: JSON.stringify({ error: 'a valid email is required' }) };

    const record = await getAccount(email);
    if(!record){

    return { statusCode: 200, body: JSON.stringify({ found: true, data: record.data }) };
```

```js
<script>
  (function(){
    let s;
    try{ s = window.localStorage; s.setItem('__t','1'); s.removeItem('__t'); }
    catch(e){
      const m = {};
      s = {
        getItem:k=> (k in m ? m[k] : null),
        setItem:(k,v)=>{ m[k]=String(v); },
        removeItem:k=>{ delete m[k]; },
        clear:()=>{ for(const k in m) delete m[k]; }
      };
    }

    /* ---------- Account sync ----------
       Every forge-* write is mirrored to the student's Netlify Blob, debounced 1s so
       rapid successive writes (e.g. typing in chat) don't spam the sync function.
       Best-effort: a failed sync never blocks the student or shows an error — see
       docs/superpowers/specs/2026-08-05-real-accounts-admin-panel-design.md's
       "Error handling" section. */
    const rawSetItem = s.setItem.bind(s);
    const knownForgeKeys = new Set();
    if(window.localStorage && s === window.localStorage){
      for(let i = 0; i < window.localStorage.length; i++){
        const k = window.localStorage.key(i);
        if(k && k.indexOf('forge-') === 0) knownForgeKeys.add(k);
      }
    }
    let syncTimer = null;
    function scheduleSync(){
      clearTimeout(syncTimer);
      syncTimer = setTimeout(runSync, 1000);
    }
    function runSync(){
      const profileRaw = s.getItem('forge-profile');
      if(!profileRaw) return;
      let email;
      try{ email = JSON.parse(profileRaw).email; } catch(e){ return; }
      if(!email) return;
      const data = {};
      knownForgeKeys.forEach(k => {
        const v = s.getItem(k);
        if(v !== null) data[k] = v;
      });
      fetch('/.netlify/functions/sync-account', {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ email, data })
      }).catch(err => console.warn('[forge-sync] failed:', err.message));
    }
    s.setItem = function(key, value){
      rawSetItem(key, value);
      if(key.indexOf('forge-') === 0){
        knownForgeKeys.add(key);
        scheduleSync();
      }
    };

    window.forgeStore = s;
  })();
</script>
```

```js
      restored = true;
    }
  } catch(err){ /* Blobs unreachable — fall through and treat as a new signup */ }

  if(!restored){
    forgeStore.setItem('forge-onboarded', 'true');
    forgeStore.setItem('forge-profile', JSON.stringify(profile));
  }

  applyProfile(JSON.parse(forgeStore.getItem('forge-profile') || 'null') || profile);

  const survey = document.getElementById('onboardingSurvey');
  survey.classList.add('splash-out');
  setTimeout(()=>{
    survey.remove();
    runSplashSequence();
  }, 500);
});
```

```js
function escapeHtml(str){
  return String(str).replace(/[&<>"']/g, c => ({ '&':'&amp;', '<':'&lt;', '>':'&gt;', '"':'&quot;', "'":'&#39;' }[c]));
}

document.getElementById('tabThisBrowser').addEventListener('click', ()=> switchAdminTab('thisBrowser'));

function switchAdminTab(tab){
  document.getElementById('tabThisBrowser').classList.toggle('active', tab === 'thisBrowser');
  document.getElementById('tabAllAccounts').classList.toggle('active', tab === 'allAccounts');
  document.getElementById('viewThisBrowser').style.display = tab === 'thisBrowser' ? '' : 'none';
  document.getElementById('viewAllAccounts').style.display = tab === 'allAccounts' ? '' : 'none';
  if(tab === 'allAccounts') loadAccounts();
}

async function loadAccounts(){
  const body = document.getElementById('accountsTableBody');
  const countEl = document.getElementById('accountsCount');
  const errorEl = document.getElementById('accountsError');
  countEl.textContent = 'Loading…';
  errorEl.style.display = 'none';
  body.innerHTML = '';
  try{
    const resp = await fetch('/.netlify/functions/list-accounts', { method: 'POST' });
    const result = await resp.json();
    if(!resp.ok) throw new Error(result.error || 'Failed to load accounts');
    countEl.textContent = result.accounts.length + (result.accounts.length === 1 ? ' account' : ' accounts');
    body.innerHTML = result.accounts.map(a => `
      <tr data-email="${escapeHtml(a.email)}">
        <td>${escapeHtml(a.firstName)} ${escapeHtml(a.lastName)}</td>
        <td>${escapeHtml(a.email)}</td>
        <td>${escapeHtml(a.course || '—')} · Sem ${escapeHtml(a.semester || '—')} · ${escapeHtml(a.batch || '—')}</td>
        <td>${a.lastSyncedAt ? new Date(a.lastSyncedAt).toLocaleString() : '—'}</td>
        <td><button class="terminate-btn" data-email="${escapeHtml(a.email)}">Terminate</button></td>
      </tr>`).join('');
  } catch(err){
    countEl.textContent = '';
    errorEl.textContent = "Couldn't load accounts — " + err.message;
    errorEl.style.display = 'block';
  }
}

document.getElementById('accountsTableBody').addEventListener('click', (e)=>{

async function terminateAccount(email){
  if(!confirm(`Permanently delete ${email}'s account? This cannot be undone.`)) return;
  try{
    const resp = await fetch('/.netlify/functions/delete-account', {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ email })
    });
    const result = await resp.json();
    if(!resp.ok) throw new Error(result.error || 'Failed to delete account');
    const row = document.querySelector(`tr[data-email="${CSS.escape(email)}"]`);
    if(row) row.remove();
  } catch(err){
    alert("Couldn't delete account — " + err.message);
  }
}
```
